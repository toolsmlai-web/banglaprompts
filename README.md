# Bangla Prompts

A minimal static HTML/CSS/JavaScript site for a Bengali AI prompt library.

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.

## Deploy on Netlify

1. Push this repository to GitHub.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Select `toolsmlai-web/banglaprompts` and the `master` branch.
4. Keep the build command empty.
5. Set the publish directory to `.`.
6. Deploy.

The repository includes `netlify.toml`, which configures these defaults automatically.
